## About the Project

**`Salary Tax & Deposit System`** is a web application that calculates salary tax and deposit interest, using **PHP** and **MsSQL**.

## Features

- **Salary Tax Calculator**: Calculates salary tax based on the Cambodian tax law.
- **Deposit Interest Calculator**: Calculates deposit interest based on the Cambodian interest rate.
- **Multilingual Support**: Supports English, Khmer, and French languages.

## Tech Stacks

- **PHP**: Backend development
- **MsSQL**: Database
- **HTML**: Frontend development
- **CSS**: Frontend development
- **JavaScript**: Frontend development
